# Multi-airline version 0.4 baseline

These eleven JSON files are the exact previous active airline inputs: six airlines and several policy topics. They were moved here when the team selected one airline (easyJet) and one underlying rule (additional large cabin-bag allowance) for the controlled airline collection in version 0.5.

This folder is not active benchmark data. Historical prompts, references and results must retain their original meaning and source context. Dataset tests use these files to verify that the earlier experimental reference labels remain preserved.

The current shared policy is `data/airlines/_policy.json`; current cases are `data/airlines/easyjet_cabin_*.json`. New scenario IDs distinguish the replacement collection from the prior runs.
